# Aliases for every plugin the client cannot load (addendum to keep-load-order)

CONFIRMED in code (be268fb, found by the rev 7 thread): `aliases::ensure_full` only made copies for .esl files named in the server list, so the spaced USSEP got no dash link and no plugin that names it as a master was rewritten; Play only switched the spaced USSEP off. This change widens `ensure_full` to every plugin in Data whose name has spaces or that names such a plugin as a master (`client_cannot_load`): the spaced one gets a hard link under the dash name (with its archives, ini, strings), the dependent one a rewritten `<name>-AD.esp` whose MAST is the dash name; plugins.txt and loadorder.txt follow, keeping `*` and place. Originals are untouched (Vortex's). Test: spaced USSEP + MoreCraftableEquipment_USSEP + SkyUI. The old test that said a spaced plugin "is not this module's business" was changed on purpose.

Open: collection::same_plugin must accept the `-AD` run name (rev 7 thread, PR 186, after 185). Implemented, PC-unverified; effectiveness on the black screen UNKNOWN. Kill: none separate; AD_KEEP_ORDER_OFF only covers the in-session keeper. NEEDS_GAME_CHECK.
