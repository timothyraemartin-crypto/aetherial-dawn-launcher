# 2026-10-12 Faster Windows release build

Faster Windows release build (draft PR claude/faster-launcher-builds-xijhie): build.yml `windows` split into `windows-checks` (Rust tests, clippy, motion/contract), `windows-ui` (Fast Play checks, 3 shards, each scenario still serial) and `windows-build` (installer + install test), side by side; release needs all. Windows jobs also run on pushes to main so tag builds can restore the Rust cache (tags read only main's cache). Runner label from repo variable AD_WINDOWS_RUNNER (default windows-latest). Measured (CONFIRMED, Actions): v0.1.136 tag run 10m51s; warm branch run 38191076708 4m08s; cold (no cache) windows-build 9m10s. Install test fails on a branch whose version is older than the latest release (the launcher self-updates at first start): keep branch version >= latest. Not merged, not released; first main run after merge is cold.
