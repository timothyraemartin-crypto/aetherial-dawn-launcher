# 2026-10-13 Client parity report

Client parity report (draft PRs claude/client-parity-hwf4tt in launcher + discord; Server Quality Plan thread 4): before the game starts, Play sends `POST /api/client-parity` (core/src/parity.rs; background, a 404 or any failure is silent) with SkyrimSE.exe version, an AE/SE GUESS (50+ cc files = AE; INFERRED from the count, not the licence), plugins.txt's switched-on order and hash, the full-plugin order the game will load (Skyrim.ccc ignored) and hash, cc* files present / switched on / set aside, Skyrim.ccc line count, archive names and hash, and the launcher's own comparison with masters.json. Names and hashes only; no paths. Also a health row "Same game files as the server" (id `parity`): Ok / Info (no list) / Warn (a server plugin missing or in the wrong place, or a cc plugin switched on); it can never be Fail, so it cannot stop Play.
